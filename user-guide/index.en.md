# User Guide

Welcome to the OpenMandriva User Guide. Start with the first steps after installation, then explore the sections below for detailed instructions on customizing and using your system.

## First Steps After Installation

Get up and running quickly with ten essential tasks: update your system, install multimedia codecs, set up snapshots with Timeshift, and more. Read [First Ten Tasks After Installation](./first-steps.en.html) right after installing OpenMandriva.

## Desktop Environments

OpenMandriva ships with a desktop environment already installed, so you start with a complete, usable desktop. Learn about the available desktop environments and how to customize your system.

## Software Management

Install, remove, and update software on your system using the package managers and tools provided by OpenMandriva.

## Network Configuration

Configure your network connections, from basic wired connections to complex wireless setups.

## Post Installation Configuration

Configure your system right after installation---set your user avatar, partition your disks, and more.

- [Post Installation Configuration](./post-installation/index.en.html)

## Maintaining Your System

Keep your system up to date and running smoothly. Switch between Rock and ROME, check recent updates, and compile custom software.

- [Maintaining Your System](./maintaining/index.en.html)

## Troubleshooting

Resolve common problems---fix a broken bootloader, connect to the internet in recovery mode, and correct time issues in dual boot.

- [Troubleshooting](./troubleshooting/index.en.html)
