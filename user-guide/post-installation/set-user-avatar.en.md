# Set Your User Avatar

The user avatar is the picture that represents your account in the login screen, user switcher, and system settings. You can choose from default images or upload a custom picture.

1. Open *System Settings*.

   ![System Settings contains many settings, among them user avatar settings.](./images/set-user-avatar-01.png)

1. Scroll to the bottom and click *Users*. 

   ![Open Users to see user settings.](./images/set-user-avatar-02.png)

1. Your account should be selected already. All accounts appear here. 

1. Click the default user image to open the avatar selection dialog.

   ![Select the default user image to open a dialog to select images.](./images/set-user-avatar-03.png)

1. Browse the available images. Pick one you like, or select *Choose File...* to select an image you already have on your machine. 

   ![Choose the avatar you want. ](./images/set-user-avatar-04.png)

1. Click *Apply* to make the change.
