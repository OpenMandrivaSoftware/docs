# Post Installation Configuration

After installing OpenMandriva, a few configuration tasks help you get the most out of your system right away. These guides cover the essential setup steps you perform immediately after installation.

## Set Your User Avatar

Personalize your desktop by assigning an image to your user account.

- [Set Your User Avatar](./set-user-avatar.en.html)

## Partition Your System

Configure separate root, home, and swap partitions during installation for more control over your disk layout.

- [Create Root, Home, and Swap Partitions](./root-home-swap.en.html)

## Configure a Printer

Set up your printer after installation---install the right driver package and let the system auto-configure your device.

- [Configure a Printer](./configure-printer.en.html)
