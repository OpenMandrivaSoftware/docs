# OpenMandriva Community

OpenMandriva is more than software. It is a worldwide community of people who like free software and like to build things together. If you want to get involved, join the conversation.

## Connect

- [Chat with us](./chat.en.html) — the OpenMandriva Matrix space for getting help and chatting with other people.
- [About us](./about.en.html) — the OpenMandriva Association behind the project.
- [Contributing to OpenMandriva](https://openmandriva.org/get-involved) — the many ways to help.
- [OpenMandriva news](https://www.openmandriva.org/en/news/) — announcements and updates.

## Support

- [Forum](https://forum.openmandriva.org/) — ask questions and help other users.
- The OpenMandraiva Matrix room `#openmandriva:matrix.org`, for quick Q&A and help getting started. Start it through the [Matrix space](https://matrix.to/#/#openmandriva-space:matrix.org) using any [Matrix client](https://app.element.io/#/room:#openmandriva:matrix.org) such as Element.
- The Cooker channel `#openmandriva-cooker:matrix.org`, for technical work and discussions with the development team.

OpenMandriva no longer uses IRC. We moved to Matrix in 2023, so use a Matrix client such as [Element](https://app.element.io/#/room/#openmandriva:matrix.org).
