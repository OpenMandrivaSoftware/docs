# Current Releases

OpenMandriva maintains two current release lines. *ROME* is the rolling release, updated monthly. *OpenMandriva Lx 6.0 Rock* is the stable release, updated annually. Read the release notes and errata for your version before reporting an issue.

## ROME

ROME is the rolling edition published by the OpenMandriva Association. It holds the newest packages that the team considers ready, so it stays up to date but should still work as a daily system. See:

- [ROME Release Notes](/community/releases/rome-release-notes/)
- [ROME Errata](/community/releases/rome-errata/)
- [ROME Changelog](/community/releases/rome-changelog/)

## Rock 6.0

OpenMandriva Lx 6.0 (codename *Vanadium*) is the current stable release. It is best for business, servers, and users who do not like change. See:

- [OpenMandriva Lx 6.0 Release Notes](/community/releases/rock-6.0-release-notes/)
- [OpenMandriva Lx 6.0 Errata](/community/releases/rock-6.0-errata/)
- [OpenMandriva Lx 6.0 Changelog](/community/releases/rock-6.0-changelog/)
