# Premiers pas

Les premiers pas avec OpenMandriva sont faciles et ne prennent que trois étapes. Cependant, avant d'entreprendre ces étapes, il est important de sauvegarder votre système. Bien qu'il soit possible d'installer OpenMandriva à côté de Windows ou d'un autre système d'exploitation, il s'agit d'une configuration complexe. Vous devez donc disposer d'une sauvegarde de vos données au cas où quelque chose se passerait mal.

Sachez par ailleurs que de l'aide est à un clic de vous sur les forums. Si vous avez des questions ou des préoccupations avant votre installation, n'hésitez pas à y poser une question.

Une fois votre sauvegarde effectuée et que vous êtes prêt·e à commencer, installer OpenMandriva ne prend que trois étapes.

## Étape une : Télécharger OpenMandriva

OpenMandriva est proposé dans plusieurs éditions : Rock, ROME et Cooker. Chacune a ses atouts ; votre première décision est de choisir quelle édition vous convient.

## Étape deux : Créer une clé USB d'installation

Une fois que vous avez选择和 téléchargé OpenMandriva, la prochaine chose à faire est de créer une clé USB amorçable. Vous aurez besoin d'une clé d'au moins 8 Go de stockage. Vous perdrez toutes les données actuellement présentes sur la clé ; elle doit être dédiée à la création de l'installateur, alors si des données y sont déjà présentes, assurez-vous de les copier ailleurs.

## Étape trois : Installer OpenMandriva

Une fois votre installateur USB prêt, insérez-le dans un port USB disponible, démarrez votre ordinateur vers son menu de démarrage, choisissez le périphérique USB, et l'installateur OpenMandriva démarre sur votre système. À partir de là, suivez la routine d'installation et installez OpenMandriva.

Voilà qui est un aperçu général de la procédure. Quand vous serez prêt·e à commencer, suivez les instructions dans les liens ci-dessous.
