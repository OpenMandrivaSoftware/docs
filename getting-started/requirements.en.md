# System Requirements

OpenMandriva Lx aims to take advantage of recent hardware, so you should not consider it suitable for older systems.

## For Regular PCs

If you plan to install OpenMandriva on a regular PC, ensure the processor is 64-bit (also referred to as x86\_64). The distribution will not work on 32-bit only processors (x586). Intel stopped producing 32-bit only processors in 2011, so any recent PC has a 64-bit processor.

## Minimum Configuration

| Component | Minimum |
|---|---|
| Processor | 64-bit (x86\_64) |
| Memory | 2 GB RAM |
| Disk space | 125 GB |

- You need at least 2 GB of memory to run the Plasma Desktop environment (the default) and most standard applications (browser, word processing, music listening).
- Most games and some websites may require more resources for smooth operation.
- Consider using an SSD rather than a mechanical drive for the system (you can still use mechanical drives as external disks with a dedicated device).

## Recommended Configuration

Linux generally needs less resources than Windows or macOS. However, other software may require the same amount of resources regardless of the operating system. Adapt your hardware to the needs of the software you plan to use.

As of 2021, you can be comfortable with at least 8 GB of RAM.
