# Télécharger OpenMandriva

Vous avez plusieurs bons choix à faire en téléchargeant OpenMandriva. Comme OpenMandriva est optimisé pour plusieurs architectures, telles que x86_64 (Intel), znver1 (AMD) et aarch64 (ARM), vous pouvez choisir la version qui convient le mieux à votre système.

Par-dessus ça, OpenMandriva est proposé dans plusieurs éditions :

- **Rock** : puissante et stable, Rock est construite sur une base solide qui ne reçoit que des correctifs de sécurité. Elle reçoit des mises à jour environ une fois par an.
- **ROME** : signifie Rolling OpenMandriva Edition. ROME reçoit des mises à jour environ mensuellement, en suivant les dernières versions. Si vous êtes développeur·se et que vous avez besoin du dernier logiciel sur un système stable, ROME est l'édition qu'il vous faut.
- **Cooker** : notre édition de développement. Ne faites tourner Cooker que si vous avez besoin de la toute dernière version, ou si vous travaillez sur OpenMandriva lui-même. Vous *pouvez* faire tourner Cooker sur votre système principal, mais vous devez suivre les développements sur notre chat Matrix pour savoir quand il est sûr de mettre à jour, sinon vous risquez de casser votre système.

Télécharger OpenMandriva nécessite donc simplement 1) de connaître votre architecture, et 2) de savoir quelle édition vous voulez.

## Choisissez votre architecture

Vous devez savoir quel type d'ordinateur vous avez avant d'installer OpenMandriva dessus. Une règle rapide pour les PC est la suivante :

- Si vous avez un processeur Intel, choisissez l'architecture x86_64.
- Si vous avez un processeur AMD et que votre ordinateur a été acheté après 2017, utilisez l'architecture znver1. Sinon, utilisez l'architecture x86_64.

Vous pouvez généralement savoir si vous avez Intel ou AMD à l'autocollant présent sur votre machine. Sinon, si vous êtes sous Windows, vous pouvez aller dans Paramètres → À propos de ce système et y voir l'architecture de votre processeur.

Si vous installez sur un Raspberry Pi ou un autre système à base d'ARM, utilisez la version aarch64.

## Choisissez votre édition

Une fois que vous connaissez votre architecture, choisissez entre la version stable Rock, la version à jour ROME, ou, plus rarement, pour des cas particuliers, la version Cooker.

La plupart des utilisateurs devraient choisir la version ROME, pour bénéficier du meilleur des deux mondes : stabilité et mise à jour.

Parfait ! Maintenant que vous êtes prêt·e, rendez-vous sur la page de [sélection des versions](https://openmandriva.org/release-picking/) et téléchargez votre fichier ISO d'OpenMandriva !
