# Preparing Your System

Before you build and submit your first package, prepare an isolated environment. Cooker---OpenMandriva's development branch---is unstable and can break at any time. Running it on your daily system risks breaking your working desktop.

This section covers three preparations:

1. [Installing and Using Virt Manager](./preparing-your-system/index.en.html)---set up the virtualization platform that runs your Cooker virtual machine.
2. [Creating a Cooker VM](./preparing-your-system/creating-cooker-vm.en.html)---download a Cooker ISO and install it in a virtual machine.
3. [Installing Packaging Tools](./preparing-your-system/packaging-tools.en.html)---install the `packaging-tools` package and learn the `v*` template utilities.

Complete all three before you start writing spec files.
