# Contributing to OpenMandriva

OpenMandriva is 100% community driven, and it runs on volunteers. You can contribute in many ways.

## Give Your Time

Help in the areas below. Each one needs people.

- Contribute code to packages and infrastructure
- Write and maintain documentation
- Translate the interface and documentation to your language
- Provide support on the forum and in chat channels
- Report bugs and help triage incoming issues
- Test new software and report findings
- Design artwork and website layouts
- Run servers and services for the project

## Spread the Word

Use the [artwork](../community/artwork.en.html) to promote OpenMandriva and the values behind it.

## Share Your Ideas

Tell the community what you need and what you're struggling with. Report the problems you find; developers use them to improve OpenMandriva.

## Donate

OpenMandriva is a non-profit association. The OpenMandriva Association welcomes all donations, no matter the size.

[Donate](https://www.openmandriva.org/donate) to the OpenMandriva Association.
