# OpenMandriva Cooker

Cooker is the development branch of OpenMandriva Lx. It reflects the current progress of work across all lines, and is considered a moving, unstable target.

## Technical Overview

The OpenMandriva Lx distribution is made possible by two major fields of technical contribution:

- Creation and maintenance of the tools, configuration, and art special to the distribution---such as the installer, the configuration center, and themes.
- Consistent packaging of several thousand programs and libraries so they are available to users in a simple, unified way.

Guidelines and rules for both areas are documented in the [repository policies](../community/releases/repository-policies.en.html).

## Using Cooker

Advanced users and developers who want to experiment with unstable software can download the latest Cooker snapshot ISO files:

- [x86_64 ISO](https://abf.openmandriva.org/platforms/cooker/products/71)
- [znver1 ISO](https://abf.openmandriva.org/platforms/cooker/products/69)

> **Warning:** OpenMandriva cannot provide support for Cooker systems due to its unstable nature. Use it only in a test environment.
{: .warning }
